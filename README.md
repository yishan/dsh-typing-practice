# dsh-typing-practice

A typing practice page for the [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) Web UI: English, Chinese and Cantonese text, recent local conversation passages, native IME input, Pinyin and Jyutping hints, live speed and accuracy, local best scores, practice history and optional mechanical keyboard sounds.

给 DeepSeek Harness Web GUI 加的「打字练习」插件：英文、中文和粤语文本练习，可选默认语料或近期本地对话，使用自己的输入法上屏，可查看拼音或粤拼提示，实时统计速度与准确率，提供机械键盘音效选择，最佳成绩和练习历史存在本机浏览器。

> 非官方项目，只是一个 DSH 插件 bundle（`dsh.bundle.patch` + `dsh.client`）。

## 功能

| 项 | 说明 |
|---|---|
| 入口 | 左侧栏「打字练习」（键盘图标）→ 主区域练习页 |
| 语料 | 英文、简体中文、繁体粤语各 96 篇；每语种短／中／长各 32 篇，与界面语言独立 |
| 本地对话 | 按当前语言，从当前 DSH profile 近 30 天的用户消息和已完成模型回复中选取片段；无结果时回退到默认语料 |
| 来源切换 | 「默认语料／本地对话语料」位于「换一段」旁；记住选项，重新打开页面时恢复；回退不改变选项 |
| 注音 | 中文带声调拼音、粤语数字声调粤拼；默认「当前词」，可选「全部」或「关闭」 |
| 练习方式 | 15／30／60 秒与短篇／中篇／长篇合为一个单选控件，与语言放在同一条栏内；两种来源均可用，记住最后选项 |
| 实时反馈 | 无边框沉浸式正文：上方一行淡化、当前及后续两行清晰、下方两行渐隐；当前行固定，文字逐行上移；保留组字预览与中英等宽混排 |
| 成绩 | 英文用 WPM，中文和粤语用字/分钟（CPM）；另显示准确率、正确字符和错误数；实时统计与结束成绩使用无边框排版，以间距和文字层级区分数据 |
| 最佳成绩 | 限时最佳按语言、时长、提示档位、规则版本和语料版本分别保存；结束后与本轮之前的最佳比较 |
| 练习历史 | 「记录」中查看最近 100 次练习和限时最佳，支持语言筛选、同篇记录及确认清空；统一保存到 `localStorage['dsh.typing-practice.v3']` |
| 键盘音效 | 默认关闭；可选 Cherry MX Blue、Cherry MX Brown、NovelKeys Cream、Holy Panda，提供音量和试听，记住选择 |
| 光标样式 | DSH 主题蓝色；竖线／下划线／方框，可选光晕与闪烁，实时预览并记住选项 |
| 操作 | 首次有效组字或直接文字输入开始计时；上屏后判分；原生退格、选区替换；始终可见的重开按钮 |
| 键盘导航 | `Tab` / `Shift+Tab` 依次切换记录、音效、光标、来源、换一段、语言、练习方式、注音选项、输入区与重开按钮；`Enter` / 空格激活按钮；练习方式仅选中项进入 Tab 顺序，方向键切换，`Home` / `End` 到首尾；设置与记录窗口可用 `Esc` 关闭并恢复焦点；组字时候选操作交给输入法 |
| 界面 | 中英双语，跟随 DSH locale；沿用 DSH 主题 token，亮/暗色自适应 |

达到所选时长时即截止，之后的文字确认和退格都不计入本轮成绩，即使浏览器尚未执行下一次计时回调。截止时仍在组字的内容不进入成绩；旧输入框迟到的组合事件不会写入重开后的新一轮。界面优先使用宿主翻译；缺少翻译时，按 `getLocale().active` 选择内置中英文文案。

页面打开时保留宿主焦点。切换语料语言或练习选项会开始新一轮，焦点留在该按钮；重开按钮将焦点送回输入区。正文没有卡片底色、描边或聚焦方框，输入状态由蓝色光标与开始前的轻量提示表示。开始输入后提示隐去，保留占位以免页面跳动。

三种语言均使用六行高的视区：上方一行淡化的已输入内容，当前行和后续两行正常显示，下方两行逐渐隐去。当前行固定在第二个行位，换行或退格跨行时即时调整内部文字位置；首行前和末行后留出空间，所以开头、末尾和回退都保持同一高度。静态透明度遮罩适配亮暗主题，汉字注音沿用原有较大行距。视区不显示滚动条，逐字输入不增加位移动画。

原生输入元素跟随当前字符定位，为系统候选窗提供锚点。持续输入和退格只移动文本视区；聚焦或调整窗口尺寸时，如果宿主裁掉了正文视区，会先将视区带入可见范围。重开回到文本开头。

选文加载与回退提示使用语料栏中的固定位置。输入区未聚焦时，卡片底部显示「点击或用 Tab 聚焦后输入」；聚焦后在同一位置显示计时规则，不覆盖正文。注音下拉框保留原生键盘操作，并单独为文字和箭头留出间距。布局测量见 [UI 微调验证记录](docs/validation/2026-11-06-ui-polish.md)。

默认语料现有 **288 篇，三种语言各 96 篇，短／中／长各 32 篇**，覆盖八类主题。每个语种保留原有 32 个场景的短文，中篇补充事件发展，长篇进一步补充细节和后续。三档分别保存为完整文本，均可独立练习；中长篇不是把无关段落拼在一起。数据通过 `family` 标明同场景关系。中文为简体，粤语为繁体口语文本。

| 篇幅 | 英文词数范围 | 中文／粤语可见字符范围 | 每语种数量 |
|---|---:|---:|---:|
| 短 | 40–79 | 80–159 | 32 |
| 中 | 80–139 | 160–279 | 32 |
| 长 | 140–220 | 280–440 | 32 |

语言与练习方式合并到同一条控件：`英文／中文／粤语 | 15 秒／30 秒／60 秒 | 短篇／中篇／长篇`。语言和练习方式各自单选，选中 30 秒后就不再同时选中某个篇幅。移除「限时／按篇」下拉框；窄屏在同一容器内换行。

首次默认 30 秒，之后记住最后选择的六个选项之一。限时继续使用原有短文池准备至少 1,200 个 UTF-16 单元，倒计时结束时结算。短篇／中篇／长篇各选择对应档位的一篇完整文本，显示用时，打完结束。

切换来源保留当前练习选项；切换选项或语言会重新选文。按篇与本地限时的「重新开始」保留当前文本，「换一段」重新选文。更改注音只重开当前文本。同篇成绩按具体文章版本区分，短、中、长不混比；限时最佳按默认／本地来源分别保存。

短文在开发阶段准备并随插件打包，运行时只做本地选择，不访问远程语料库，不调用用户模型额度。首批没有引入第三方正文，按项目 MIT 许可分发。数据与维护规则见 [语料说明](data/README.md)。

默认语料和本地对话使用同一套文本规则：英文双引号使用 `"`，撇号使用 `'`；中文和粤语双引号使用 `“”`，替换 `「」`、`『』`。清理装饰性 emoji、不可见格式字符和多余空白，全角英文字母及数字转为半角。含 `⌘`、数学符号等不支持字符的本地句子会被跳过，不通过删除有意义的符号改写句意，也不跨过被跳过的句子拼接短片段。清理发生在分句、长度计算、注音和指纹计算之前。

练习输入仍严格匹配清理后的目标文本；不自动转换用户输入的简繁字或标点，也不删除输入法自动补全的成对标点。

拼音由 `pinyin-pro` 生成，粤拼采用与 jyut 项目相同的 `to-jyutping` 引擎，结合词语上下文选音。注音在汉字上方显示；「当前词」会随输入位置移动，并保留隐藏注音的位置，避免每输入一个字就改变换行。自动注音不改写原文，未知读音留空。切换提示档位会保留当前语料并开始新一轮，三个档位的最佳成绩分别保存。

两个词库随插件打包，按所选语言在本地加载并缓存，不调用远程注音服务。首次准备注音期间暂不接收输入、不启动计时；加载失败时可重试，或关闭提示继续练习。

### 本地对话语料

在「换一段」旁选择「本地对话语料」，插件立即按当前英文／中文／粤语模式选取文本。之后点击「换一段」可重新选取。切换语言、重新打开练习页时，也会按保存的来源选取；首次使用默认为「默认语料」，不读取聊天正文。选择默认语料会取消正在进行的读取。

本地对话只使用近 30 天的用户正文和已完成的模型回复，不区分两种角色。短篇／中篇／长篇按上表档位提取完整句子。15／30／60 秒会在同一次有界读取中准备多个完整短片段，达到至少 1,200 个 UTF-16 单元后再开始练习；不在计时中继续读取，也不重复单个片段凑长度。切换语言或练习选项会取消旧请求并重新选文。

保留原文简繁字形，统一上述符号，不把普通话改写成粤语。没有合适内容、限时片段不足、读取失败或超时时，整轮回退到同语言、同练习选项的默认语料。来源切换器仍保留「本地对话语料」，下次「换一段」继续尝试本地对话；界面提示回退，历史与最佳按实际使用的默认来源记录。读取中可点击「取消选取」。

提取会跳过推理、工具调用及结果、系统上下文、代码、表格、附件和明显的密钥等片段；清理 Markdown 后只显示普通文本，不执行内容。每个候选片段只来自一条消息；按篇不跨消息拼接，限时可连续练习多个独立完整片段。拒绝引号或括号不配对、缺少句末标点及部分明显依赖上下文的片段；同次消息提取会过滤高度相似的候选。正文不持久化，限时与按篇成绩分开保存。

速度按当前正确匹配的可见字符计算：英文每五个字符折合一词；中文与粤语每个可见字符计一字，包含标点及拉丁字符。组字和选词时间计入用时。准确率按累计确认输入计算；取消组字不计错误，修正已上屏错误不抹去累计错误。使用 `Intl.Segmenter` 划分可见字符，避免把非 BMP 汉字或组合字符拆成多个计分单位。提前打完会显示实际用时，不写入完整时长最佳。

默认语料按语言记住最近 16 个已选文章 ID，并根据 `family` 避开同场景的其他长度版本。这样从短切到长时，不会立即遇到相同的开头；限时选文也避开近期按篇练过的场景。本地对话按语言记住最近 16 个文本指纹；在原有读取预算内继续寻找新片段，只有近期重复片段时选最早使用的一段，当前片段始终排除，限时会排除当前整批的所有片段。没有其他可用片段时沿用默认语料回退。近期列表在刷新后保留，存储不可用时当前页面仍在内存中去重。

### 键盘音效

点击右上角「音效」，选择声音并点击「试听」，用音量滑块调整大小。默认关闭，初始音量 30%；音色和音量随选择保存。练习进行中暂时禁用设置入口，结束或重新开始后可调整。窗口沿用页面的主题、原生下拉框与焦点样式。

首批四套声音来自 [kbsim](https://github.com/tplai/kbsim) 的 MIT 许可录音。每套含五个普通键变体，茶轴、奶油轴和 Holy Panda 另有空格、退格和回车录音；青轴的特殊键使用普通键录音。这些是具体键盘配置的录音，不代表所有同名轴体的声音。29 个原始 MP3 共 67,240 字节，保留原文件及校验值，构建后随本地 `client.audio.js` 分块按需加载。来源、版本和许可见 [素材说明](assets/audio/kbsim/README.md)与[第三方声明](THIRD_PARTY_NOTICES.md)。

仅练习输入区聚焦且可输入时响应按键。忽略长按自动重复、导航键和带 Ctrl／Command／Alt 的快捷键；组字期间按浏览器实际收到的按键播放，上屏一整词不会按汉字数量重复响。普通回车不播放，组字回车可使用回车录音。声音与计时、判分独立，不另加错误提示音或抬键声。失焦、切到后台、重开或结束会停止播放。

音频在用户选择、试听或聚焦输入区后初始化，不在页面加载时自动播放。首次加载期间的按键不会排队补播；播放失败不影响练习，可在音效窗口中点击「试听」重试。同类应用参考和本轮验证范围见[音效验证记录](docs/validation/2026-11-06-keyboard-sounds.md)。

### 光标样式

点击右上角「光标」，在预览中选择竖线、下划线或方框，独立开关光晕与闪烁。默认使用 **蓝色竖线、光晕开启、闪烁关闭**。光标颜色跟随 DSH 主题蓝，亮暗模式使用各自 token；方框保留透明内部，正文不会被色块覆盖。练习开始后暂时禁用设置入口，结束或重开后可调整。

光晕从光标向两侧柔和扩散，不改变字符尺寸或换行。输入区失焦时光标变淡，取消光晕和闪烁；组字期间保持光标常亮。开启闪烁后采用 1.2 秒的明暗变化；系统启用「减少动态效果」时停止闪烁。隐藏输入框仅作为输入法锚点，正文聚焦后也不出现外围方框，使用蓝色光标表示输入位置。输入位置、候选窗定位与计分逻辑不因样式选项改变。

设置窗口支持即时预览、Tab 导航、空格切换开关和 Esc 返回入口。浏览器布局、输入滚动与验证边界见[光标验证记录](docs/validation/2026-11-06-cursor-styles.md)。

## 安装

本插件是 DSH 的 bundle。克隆后，在 DSH 里让 agent 用 `plugin_manager` 安装**这个目录**：

```bash
git clone https://github.com/yishan/dsh-typing-practice.git
```

```
plugin_manager(action: "install_bundle", target: "/absolute/path/to/dsh-typing-practice")
```

如果你的环境里有 `dsh` CLI，也可以直接：

```bash
dsh plugin --profile <profile> add /absolute/path/to/dsh-typing-practice
```

安装后刷新 DSH Web 页面，左侧栏会出现「打字练习」。仓库包含已构建的注音与音效文件，直接安装无需自行构建；包管理器会安装 Host 所需依赖。注音分块和本地对话接口已在 DSH `0.2.2-rc.1` 验证；缺少对话查询服务时回退到默认语料，不具备相同模块加载能力的宿主可关闭提示使用。已有本地安装更新 Host 代码后，可在插件管理页关闭再开启「打字练习」。安装是 profile 级的，该 profile 下所有会话可见；删除时用 `plugin_manager` 卸载即可。

## 数据

最佳成绩和练习历史统一写入 `dsh.typing-practice.v3`，其值为以下结构的 JSON 字符串：

```js
{
  version: 3,
  best: {
    "en:30:builtin:plain:2:corpus2": { speed: 76, accuracy: 0.94, at: 1793900000000 },
    "yue:30:builtin:plain:2:corpus2": { speed: 102, accuracy: 0.98, at: 1793900000000 },
    "zh:30:builtin:current:2:corpus2": { speed: 108, accuracy: 0.97, at: 1793900000000 },
    "yue:30:builtin:all:2:corpus2": { speed: 96, accuracy: 0.99, at: 1793900000000 }
  },
  legacy: {}, // 旧版 v1 最佳单独保留，不参与新版比较
  history: [{
    id: "generated-run-id", language: "en", hints: "off", rules: 2, corpusVersion: 2,
    mode: "timed", source: "builtin", duration: 30, status: "completed",
    at: 1793900000000, elapsedMs: 30000, speed: 76, accuracy: 0.95,
    correct: 190, wrongKeys: 10, keystrokes: 200, targetLength: 1200,
    fingerprint: null, passageId: null, length: null
  }]
}
```

最佳成绩的键依次表示语言、秒数、内置语料、提示档位、评分规则版本和语料版本。新短文库使用 `corpus2` 后缀；没有后缀的旧最佳继续保留并标为“旧语料”，不参与新短文库比较。旧限时历史缺少 `corpusVersion` 时按 1 读取，新限时和默认文章的按篇历史记为 2，本地片段使用 `null`。键中的提示档位使用 `plain`（关闭）、`current`（当前词）、`all`（全部）；历史条目的 `hints` 使用 `off`、`current`、`all`。`speed` 的单位由语言决定。比较时先看速度，速度相同时比较显示到整数百分比的准确率。

每轮结束只追加一次历史，按完成顺序保留最近 100 次。限时提前打完的条目标为 `early`，保存实际用时，但不更新限时最佳。中途重开、更换语料或离开页面不生成历史。本地按篇条目使用 `mode: "passage"`、`source: "local"`、`duration: null` 和 SHA-256 文本指纹；仅与最近 100 次中相同原文、语言、提示档位和规则的成绩比较，不混比不同片段。本地限时使用 `mode: "timed"`、所选 `duration` 和整批文本指纹；最佳键例如 `en:30:local:plain:2`，与默认语料独立，历史保留实际来源。限时最佳独立保留，不受 100 条历史上限影响。

首次读取时兼容 v2 最佳与 v1 旧版最佳，不补造过去的练习历史。下一次保存将有效旧成绩一并写入 v3，原始 v1／v2 数据不改写。旧版最佳单独显示，不参与新版比较。通过「记录 → 清空全部记录 → 确认清空」可一次清空历史及新旧最佳，保留语料来源选项；空的 v3 仍为有效数据，刷新不会重新导入旧成绩。手动删除 v3 会重新触发旧数据导入，因此请使用界面的清空入口。保存失败会提示，本页仍可查看尚未保存的成绩；清空失败则保留原记录。

近期选文单独保存在 `dsh.typing-practice.recent.v1`：包含 `version: 1`、`corpusVersion: 2` 及按语言分组的 `builtin` 段落 ID 和 `local` SHA-256 指纹列表。各列表最多 16 项，无正文、标题或会话位置。默认段落列表在语料版本变化时重置，本地指纹保留；清空练习成绩不清除此列表。

练习方式保存在 `dsh.typing-practice.exercise.v2`，例如 `{"version":2,"preset":"30"}` 或 `{"version":2,"preset":"long"}`。只允许 `15`、`30`、`60`、`short`、`medium`、`long` 六个字符串值，首次默认 `30`。有效 v2 优先；缺少 v2 时迁移旧 `exercise.v1` 的模式／篇幅，旧本地来源仍按篇恢复。旧存储不改写，清空成绩不删除这些设置。

语料来源单独保存在 `dsh.typing-practice.preferences.v1`：`{"version":1,"source":"local"}` 或 `{"version":1,"source":"builtin"}`。该设置与成绩分开；无效设置回退到默认语料。保存失败会提示，下次打开时可能需要重新选择。

音效单独保存在 `dsh.typing-practice.sound.v1`，例如 `{"version":1,"pack":"cream","volume":30}`；`pack` 可为 `off`、`mxblue`、`mxbrown`、`cream`、`holypanda`。清空练习记录不会清空音效选项。无效音色回退为关闭，无效音量回退为 30%。

光标单独保存在 `dsh.typing-practice.cursor.v1`，例如 `{"version":1,"shape":"line","glow":true,"blink":false}`；`shape` 可为 `line`、`underline`、`outline`。初始化时读取，清空记录不改变光标选项。缺少或无效字段使用对应默认值；保存失败时当前页仍生效，并在设置窗口提示。

本地对话模式通过当前 DSH Host 读取当前 profile 的聊天历史，不向外部服务上传正文，不调用远程模型或翻译服务。选中的片段只留在本次页面内存中；浏览器存储仅保留来源选项、成绩统计与片段指纹，不保存对话正文、标题、会话 ID 或消息位置。没有收藏、正文缓存或跨设备同步。

## 结构

```
dsh-typing-practice/
├── package.json        # bundle 清单 + dsh.client 声明（platform: web, inject: ["slots"]）
├── cordis.patch.yml    # 只插入一行 Host 插件
├── index.js            # Host 半：注册受宿主鉴权保护的近期语料接口
├── client.js           # Client 半：手写界面 + 标记范围内生成的离线语料
├── client.pinyin.js    # 生成文件：拼音引擎与对齐适配
├── client.jyutping.js  # 生成文件：粤拼引擎与对齐适配
├── client.audio.js     # 生成文件：音频播放器与四套按键录音
├── data/               # 288 篇分档原创文本、场景关联与维护规则
├── assets/audio/kbsim/ # 原始录音、许可与固定版本的文件校验清单
├── src/               # 注音、字符对齐、语料提取与接口、audio-player.js 音频播放器
├── scripts/build.mjs  # 校验语料、嵌入默认文本，并打包 DSH 异步模块
├── scripts/check-corpus.mjs # 符号、长度、完整性、重复度与来源检查
├── tests/             # 输入、计时、记录、注音、语料、音效及偏好记忆测试
├── icon.svg            # 插件图标（原创键帽）
├── locale/{zh,en}.json # 插件管理页的标题 / 描述
├── LICENSE
├── THIRD_PARTY_NOTICES.md
└── README.md
```

实现要点：

- 挂载点：`sidebar.panellist`（`id: typing-practice`，order 15）+ `main`（`key: typing-practice`）。
- 计时、默认短文选择、成绩统计在浏览器端；Host 的 `GET /api/typing-practice/recent?language=en|zh|yue` 返回一个片段或回退原因。
- Host 使用当前 profile 的 `sessionQuery.listSessions` 和可取消的 `observeSession`；每次观察结束均释放。桌面 Client 优先使用宿主 `__DSH_TRANSPORT__.fetch`，Web 使用相对路径请求。
- `mdast-util-from-markdown` 在 Host 解析 Markdown。先过滤事件时间、来源和内容类型，再统一符号并按句子边界选文；保留来源位置与清理后文本指纹，接口不返回完整聊天日志。
- `client.js` 通过 `window.__ModuleLoader__.load` 注册，React 来自页面运行时；不 import 任何 Harness Client 包。
- 注音代码构建成两个独立的 DSH chunk，通过 `require.async` 按需加载。构建后更新主入口时间戳，使宿主刷新词库版本。
- 音效是独立的 DSH chunk，内嵌短录音；Web Audio 解码后缓存，最多叠加八个声音。音色切换、迟到加载与卸载均取消旧播放。
- 页面文案注册到 Client locale 服务，切换语言自动刷新。

## 开发

- 改 `client.js` 后刷新页面即可；改 Host 入口或语料模块后，在插件管理页关闭再开启本插件，或重启 DSH。修改 `data/passages.json`、`src/practice-text.js`、注音、音频源码、录音素材或依赖后，重新构建并一并提交生成文件与第三方声明。
- 静态检查：

```bash
node --check client.js
node --check index.js
python3 -m json.tool package.json > /dev/null
```

- 安装开发依赖、校验并构建离线语料、注音和音效分块，然后运行回归测试（Node 内置测试运行器）：

```bash
npm ci
npm run check:corpus
npm run build
npm test
```

## 已知限制

- 当前已交付输入层、三语示例语料、拼音／粤拼提示、近期本地对话选文、最佳记录、练习历史、键盘音效和光标样式。手动导入、收藏和自定义主题色尚未实现，后续见 [多语言规划](docs/plans/2026-11-06-multilingual-practice-plan.md)。
- 每次最多检查 30 个会话，Host 使用 8 秒协作取消预算，Client 最长等待 12 秒；下次从后续会话继续。无结果表示本次预算内未找到，不保证遍历全部历史。宿主读取超大会话仍可能加载整份日志，预算不是严格的磁盘字节上限。
- 粤语识别使用用词特征初筛，可能漏选或误选；不保证所有片段的语言与自然度。不同宿主版本的历史格式可能需要适配，失败时回退默认语料。来源仅限当前 DSH profile，不读取其他应用历史。
- 自动注音和分词仍可能有误。内置粤语已为「慢慢行」「返到屋企」增加上下文读音校正；暂未提供用户选音、人工覆盖或读音教学功能。
- 内置库每种语言有 32 个场景的三档版本，共 96 篇；同场景各档共享开头，并非 96 个独立故事。长期使用仍会重复。规则校验不等同于语义或母语审校；自动注音有读音覆盖不代表逐词读音全部正确。近期去重按精确文本指纹进行，跨请求的小幅改写可能再次出现。
- Windows、其他输入法，以及组字中跨行、缩放、截止等组合操作仍需真实环境回归。自动测试通过不代表所有输入法均已验证。
- 切换侧边栏面板会卸载页面，进行中的练习重置；已保存的最佳成绩和历史不受影响。练习进行中暂时禁用记录入口，结束或重开后可查看。
- 成绩只存在本机浏览器，不跨设备同步。
