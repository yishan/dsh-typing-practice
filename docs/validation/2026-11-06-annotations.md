# 拼音与粤拼提示验证

日期：2026-11-06。基线：`35aaced`，验证对象为当前未提交的注音实现。宿主：macOS 上 DeepSeek Harness `0.2.2-rc.1`。输入层的先行证据见 [IME 验证记录](2026-11-06-ime.md)。

## 实现范围

- 中文采用 `pinyin-pro@3.29.5`，显示带声调符号的拼音；粤语采用 `to-jyutping@3.1.1`，显示数字声调粤拼。
- 默认显示当前词，可切换关闭或全部。当前词按光标所在词范围显示；隐藏的注音仍占位，不随光标推进重新排版。
- 注音按原文偏移映射到可见字符，不修改原文、评分答案或用户输入。非汉字不加注音，未知读音留空。
- 词库按语言通过 DSH `require.async` 加载；英文不加载词库。注音结果最多缓存 24 段文本。
- 等待注音时不接受输入、不启动计时。加载失败可重试或关闭提示；旧轮迟到的加载结果不会覆盖新一轮。
- 切换提示模式保留语料、重置本轮，最佳成绩按关闭／当前词／全部分别保存。关闭模式继续使用原 v2 `plain` 记录。

## 构建与依赖

`npm run build` 使用 esbuild 生成两个自包含的浏览器 CJS 模块，并包装为 DSH `id + chunk + factory` 注册格式。生成文件不使用远程 CDN。主入口在分块全部写入后更新时间戳，使宿主为新词库生成新的模块版本。

| 文件 | 未压缩传输编码前的文件大小 |
|---|---:|
| `client.pinyin.js` | 304,919 字节 |
| `client.jyutping.js` | 390,338 字节 |

引擎来源：[pinyin-pro](https://github.com/zh-lx/pinyin-pro)、[to-jyutping](https://github.com/CanCLID/to-jyutping)。随包保留对应版本的完整许可，见 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)。

`npm pack --dry-run --json` 通过，安装包包含两个注音分块与第三方声明，共 12 个文件，压缩后约 438 KB。主入口、Host 入口、两个生成分块的 `node --check`，以及 `git diff --check` 均通过。

对内置粤语补充了两处上下文校正：「慢慢行」的「行」为 `haang4`，「返到屋企」的「返」为 `faan1`。读音依据分别为粤典的[行](https://words.hk/zidin/%E8%A1%8C)与[返](https://words.hk/zidin/%E8%BF%94)词条。校正只改变提示，不替换原文。其他自动读音仍需要人工审校。

## 自动回归

`npm test`：61 项通过，0 失败。保留输入层阶段 47 项，新增 14 项：

- 拼音与粤拼上下文多音字；粤语词界和两处校正。
- 混合文字、标点、非 BMP 汉字、组合字符与原文偏移对齐；未知读音留空。
- 两个实际生成文件的 DSH 模块注册、独立执行和与源码结果一致。
- 12 段内置中文／粤语语料的每个汉字均有读音；原文连接后完全一致。读音覆盖不等于逐字人工审校通过。
- 按语言懒加载与重用、加载期间拒绝输入、加载失败重试、旧语言请求隔离。
- 提示切换建立新一轮并隔离旧组合事件；关闭提示后可继续练习，迟到的注音结果不影响本轮。
- 三个提示档位的最佳记录分别保存并恢复。

组件测试使用 React hooks 替身和受控时钟；不模拟宿主加载器或操作系统候选窗的全部行为。

## 验证边界

- 没有新增 Windows 或其他输入法的真实测试。跨行／缩放时的实际候选窗，以及组字中截止、重开等组合操作仍需真机回归。

- 内置 12 段语料已验证原文完整性和汉字读音覆盖，未完成独立语言审校。
- 本阶段未重跑此前基线的全部亮暗主题与减少动画检查，不将历史检查数量计入本轮结果。
