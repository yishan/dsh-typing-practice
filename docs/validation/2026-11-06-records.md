# 最佳记录与练习历史验证

日期：2026-11-06。开发基线：`93fef03`。目标宿主：macOS 上 DeepSeek Harness `0.2.2-rc.1`。本文对应工作区实现，不表示已提交或发布。

## 实现范围

- 页面右上角新增「记录」入口，打开原生 dialog；提供「最近练习」与「限时最佳」两个视图，支持语言筛选和同篇记录筛选。
- 已结束练习只写一次，保留最近 100 次。中途重开、切换或卸载不生成历史。限时提前打完保存实际用时，标识提前完成，不更新限时最佳。
- 限时最佳保持语言、15／30／60 秒、提示档位、规则版本隔离，独立于历史保留上限。速度相同则比较整数百分比准确率。
- 结果与本轮之前的最佳比较。本地对话只比较最近 100 次中相同文本指纹、语言、提示档位和规则的完成成绩。
- 本地存储白名单只包含统计、随机练习 ID 和片段指纹，不保存正文、标题、会话 ID、消息位置或路径。
- 清空需界面确认，一次清空历史及新旧最佳，保留语料来源选项；失败时保留原记录并允许重试。
- 练习进行中禁用记录入口。打开窗口取消未完成的选文请求，防止迟到返回改变练习或抢走焦点。

## 存储与迁移

`dsh.typing-practice.v3` 是单一权威对象，包含 `version`、`best`、`legacy`、`history`。完成与清空均为一次 `setItem`，避免最佳与历史分开写入产生部分成功。

没有有效 v3 时读取 v2 最佳和 v1 旧版最佳，仅在下一次保存时写入 v3；不凭旧最佳生成历史。原始 v1／v2 键不改写。有效的空 v3 阻止旧成绩复活。损坏的条目会过滤，历史按白名单重建。

保存失败时记录仍留在当前页面内存中，显示保存提示；之后成功完成一轮会一并保存尚未落盘的记录。离开前仍未成功保存的记录不保证恢复。多窗口并发写入协调、导出及跨设备同步不在本轮范围。

## 自动测试

`npm test`：93 项通过。新增 10 项覆盖：

1. 同一结果不重复追加；低分仍保存历史；结果与更新前最佳比较。
2. v1／v2 兼容读取，不改写原始键，不补造历史；同速度更高准确率更新最佳。
3. 提前完成与完整限时区分；中途重开和语言切换不生成历史。
4. 同篇、语言、提示档位隔离；不同指纹不混比；存储排除正文及来源标识。
5. 超过 100 条截断，重挂载后恢复；限时最佳不随历史淘汰。
6. 清空确认、Esc 取消、原子写入、来源偏好保留及旧成绩不复活。
7. 清空失败保留数据，可重试。
8. 保存失败保留内存成绩，后续成功保存可恢复。
9. 进行中不能打开记录；打开记录取消选文，迟到请求不生效。
10. 无效、重复、带多余字段的历史安全过滤。

既有输入、计时、Unicode、注音、语料提取与接口测试继续通过。组件测试使用 React hooks 替身和受控时钟；不替代浏览器 DOM 或真实输入法验证。

## 真实 DSH 检查与边界

本轮开始时读到真实 DSH 的中文本地片段完成状态，确认之前的选文与注音界面已加载。记录功能接通后，在真实 DSH 可访问性树中观察到 30 秒英文已完成成绩、首次同条件完成提示及「记录」入口。打开记录窗口后，树中出现对应历史条目，焦点在关闭按钮；关闭后焦点返回「记录」。没有清空或改写用户原有记录。

桌面自动化的可访问性状态与截图更新不一致，部分点击没有稳定触发预期目标。因此真实宿主的新增证据仅覆盖上述入口、历史内容和关闭焦点，不将模拟宿主的完整弹窗视觉／键盘验证扩展为真实 DSH 全面验收。真实宿主本轮未验证全部语言筛选、清空、跨 profile、其他操作系统或新的 IME 组合矩阵。
