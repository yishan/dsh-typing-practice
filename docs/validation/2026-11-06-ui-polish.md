# 提示文案与下拉控件微调

日期：2026-11-06。范围：修复提示导致的布局跳动、聚焦提示遮挡正文和下拉箭头间距；保留现有颜色、卡片和整体结构。按 `emil-ui-polish` 的稳定尺寸、固定字重和装饰元素不拦截点击原则处理。

## 复现与修改

- 原回退提示作为临时段落插入语料栏和工具栏之间。桌面上出现时，统计区和练习卡片均下移 34px。
- 原计时说明与语言、时长、注音控件共用可换行工具栏，长说明会影响控件排列。现在输入说明放在卡片底部、重开按钮左侧，并预留不同说明的最大尺寸。
- 原聚焦提示绝对定位在正文右下角，覆盖最后一行。现在未聚焦显示聚焦方法，聚焦后在同一位置显示计时说明，完全移出文本视区。
- 语料状态在语料栏内原位替换，使用不可访问的尺寸占位元素预留翻译和换行空间；可见反馈保留 `role="status"`。加载按钮也为「换一段／取消选取」预留同一宽度。
- 「完成一段」使用原时长控件的位置，保持控制区占位；本地片段中的限时按钮隐藏并禁用，不进入键盘导航。
- 注音准备状态移入卡片底部，不再插入统计区上方。加载失败的重试操作仍保留。
- 下拉框保留原生 `select`，文字左留白 12px、右留白 36px，12px 箭头距右边 12px；箭头为无交互 SVG，不拦截点击。
- 分段按钮选中与未选中使用相同字重；焦点框保留并统一使用前景色 token。
