# 近期本地对话语料验证

日期：2026-11-06。开发基线：`9012afd`。目标宿主：本机 DeepSeek Harness `0.2.2-rc.1`。本记录对应工作区实现，未代表已发布版本。

## 交付范围

按用户最新调整，在「换一段」旁增加「默认语料／本地对话语料」切换器，记住来源选项。本地对话按当前英文／中文／粤语从近 30 天正文中选取，不区分用户与模型，不增加会话、角色、长度或候选预览选项。

| 场景 | 当前行为 |
|---|---|
| 首次打开、默认来源 | 使用原有内置文本，不读取聊天正文 |
| 选择本地对话 | 保存来源并立即选取当前语言片段 |
| 已保存本地来源后重新打开 | 恢复来源并按当前语言选取 |
| 切换语言 | 沿用来源；本地来源重新筛选对应语言 |
| 点击换一段 | 默认来源重新生成；本地来源重新读取近期片段 |
| 无结果、服务缺失、失败、超时 | 使用默认语料，显示反馈；仍保留本地来源选项 |
| 读取中取消或切回默认 | 取消旧请求；迟到结果不覆盖当前练习 |
| 片段练习 | 打完整段结束，按实际用时统计，不写入限时最佳 |
| 来源偏好保存失败 | 本次切换仍生效，提示下次需重新选择 |

## Host 接口与数据边界

`index.js` 注册 `GET /api/typing-practice/recent`。接口通过宿主的 owner-only Fetch 通道鉴权，使用当前 profile 的 `sessionQuery.listSessions` 与 `observeSession({ signal, projectionMode: 'none' })`。依据为本机安装包中实际的连接、会话查询与消息模块；未依赖旧 checkout 猜测方法签名。观察句柄在 `finally` 释放。

桌面端必须通过 `window.__DSH_TRANSPORT__.fetch` 访问 Host。初次验证时，相对全局 `fetch` 指向桌面静态页面，触发默认语料回退；接入宿主请求通道后，实际选文成功。Web 环境仍使用相对路径 `fetch`。

- 时间条件按消息事件时间计算，为请求时刻往前 30×24 小时，排除未来时间。旧会话中的近期消息仍可使用。
- 只读取真实用户正文和已完成的模型回复。跳过子代理会话、推理、工具块及结果、系统／开发者注入上下文、失败和未完成回复。
- 使用 Markdown AST 提取普通段落；排除代码、HTML、表格、媒体、明显凭据、URL、路径等不适合练习的段落。此过滤是练习适用性规则，不宣称完整的敏感信息识别。
- 按完整句子截取，英文 40–100 词，中文／粤语 80–200 个可见字符；不同消息不拼接。
- 粤语用词特征仅作启发式筛选，保留原文，不翻译或改写，仍可能漏选和误选。
- 返回一个片段及来源会话、事件、文本块、原文行、清理后范围和指纹。不会返回完整日志或候选列表。
- 正文仅在运行内存使用，不写浏览器存储、不上传外部服务。来源选项单独保存到 `dsh.typing-practice.preferences.v1`，不改变原有最佳成绩结构。

每次最多检查 30 个会话，逐次轮换起点；找到有候选的会话后选一段返回。Host 8 秒协作取消、同时最多两次读取；Client 使用 12 秒 Promise 超时上限。单条文本块超过 20,000 UTF-16 单元时跳过；每个会话处理最近 20,000 事件，文本预算 200,000 单元、候选上限 30。

无结果只表示本次预算内没有结果。宿主可能先加载完整会话日志，协作取消不等于严格的磁盘字节或内存上限。
