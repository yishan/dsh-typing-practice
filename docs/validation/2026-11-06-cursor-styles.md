# 光标样式验证

日期：2026-11-06。

## 改动范围

按用户提供的截图增加向两侧扩散的柔和光晕，使用 DSH 主题蓝。沿用当前页面布局、字号、注音、文字视区行数与输入锚点。

- 右上角新增「光标」入口，提供竖线／下划线／透明方框，即时预览，光晕与闪烁独立开关。
- 默认竖线、光晕开启、闪烁关闭。选项通过 `dsh.typing-practice.cursor.v1` 保存，初始化读取；不混入成绩、音效或语料来源设置。
- 使用 `--dsw-alias-brand-primary-new-colorprimary-new-color`。当前宿主样式中，亮色解析为 `rgb(65, 118, 230)`，深色解析为 `rgb(86, 134, 254)`；原先的 `brand-primary` 是黑白中性色。
- 光标为绝对定位的伪元素。光晕向左右各扩散，不占文字排版空间。视区用等量的负外边距与内边距保留两侧光晕空间，正文宽度不变。
- 失焦时光标变淡、关闭光晕及闪烁；组字期间关闭闪烁，减少动态效果规则同样禁用闪烁。结束后的光标消失沿用既有行为。
- 取消隐藏输入框自身的原生焦点轮廓，避免它形成套在蓝色光标上的小框。可见练习区域的焦点轮廓保留。

## 浏览器检查

环境：本地独立模拟宿主页，加载实际 Client、注音分块、React 18 和当前 DSH 主题 CSS。测试数据与存储使用独立端口，不修改原生 DSH 的偏好与记录。

| 检查 | 结果 |

| 三种形状 | 即时预览生效；下划线为 3px，方框内部透明、边框 2px |
| 光晕与闪烁 | 光晕关闭后 computed box-shadow 为 none；开启闪烁后 animation-name 为 tp-cursor-blink |
| 刷新恢复 | 方框、光晕关闭、闪烁开启三项在刷新后一起恢复 |
| 亮暗主题 | 两种模式分别解析为宿主对应蓝色，深色预览与实际练习区已目视检查 |
| 减少动态效果 | 测试宿主页将现有媒体规则切到匹配状态，闪烁开启时 computed animation-name 为 none |
| 键盘操作 | Tab 从关闭按钮到形状、光晕；空格切换光晕；Esc 关闭后焦点返回入口 |

| 控制台 | 最终检查无 warn／error |

## 回归与边界

现有 104 项 Node 测试通过，覆盖输入截止、IME 事件、成绩、语料、注音与音效；`node --check client.js` 与 `git diff --check` 通过。此次设置和视觉行为由浏览器交互验证，未添加只复刻 CSS 或控件实现的单元测试。
