# 单页设置验证（2026-11-06）

基于 `50b0a45`，按用户要求将原注音、音效、光标标签页合并为同一设置页面。

## 显示方式

- 三个小标题纵向排列，选项全部展开，不再需要切换标签页。
- 注音：拼音／粤拼显示范围。
- 音效：声音选择与试听同一行，其下为音量与素材来源。保留一行加载反馈占位，较长错误提示按需要展开。
- 光标：即时预览、形状选择，以及并排的光晕与闪烁开关。
- 桌面窗口宽 520px，高度按内容收缩；480px 以下使用标签在上、控件在下的布局。内容较高时仅设置内容区滚动，顶部标题及关闭按钮保留位置。
- 打开时聚焦注音选择，使用原生 Tab 顺序。保留偏好保存、关闭时停止试听、Esc 关闭和返回入口焦点。
