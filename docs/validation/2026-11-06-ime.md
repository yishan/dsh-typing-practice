# 中文与粤语输入验证

日期：2026-11-06。基线：`35aaced`；验证对象为输入层阶段未提交的 `client.js` 与 `tests/client.test.js`。宿主：macOS 上的 DeepSeek Harness `0.2.2-rc.1`。本文保留该阶段的证据；同日后续注音实现和新增验证见[注音验证记录](2026-11-06-annotations.md)。

## 已交付范围

- 英文、简体中文、繁体粤语三种内置语料模式。中文和粤语分别包含六段原创示例短文。
- 原生 textarea 保留输入法缓冲；组字预览与正式判分分开，确认后按缓冲变化批量计分。
- 首次非空组字启动计时。截止后提交不进入成绩，重开前的组合事件不进入新一轮。
- 英文用 WPM；中文与粤语用 CPM，包含标点。可见字符分割使用 `Intl.Segmenter`。
- 输入锚点随光标、内部滚动和视区尺寸更新；中文、粤语使用三行视区。
- v2 最佳成绩按语言、时长、内置语料、无注音和规则版本区分；保留 v1，旧记录单独标识。

## 自动测试

`npm test`：47 项通过，0 失败。使用实际发布脚本、React hooks 替身、原生缓冲替身及受控时钟。

覆盖范围：三个时长的截止前／截止瞬间／延迟回调，直接输入与退格，首次组字计时，中文和粤语整词提交，候选按键不拦截，取消组字，组合结束后的重复 input，连续输入相同汉字，截止与组字重叠，旧输入节点事件，非 BMP 汉字和组合字符，选区替换、累计错误、成对标点、粘贴回退拦截，语言记录隔离，提前完成、旧记录保留和存储失败。

这些测试验证事件处理和评分规则，不验证操作系统的事件产生方式或候选窗。

## 真实 DSH 观察与用户验证

| 项目 | 证据与结果 |
|---|---|
| 插件加载 | 已安装插件直接加载新代码；英文、中文、粤语控制和 CPM 界面可见 |
| 原生组字 | 物理按键触发输入法组字；页面显示 `ji n` 预览，错误数保持为 0 |
| 候选确认 | 空格后原生缓冲为「技能」，目标开头为「学习」；错误数一次增加 2，光标前进两个汉字，没有把组字字母计入错误 |
| 组字时间 | 确认后剩余时间为 23 秒，组字和选词期间的时间已计入 |
| 候选窗位置 | 用户在同轮对话同步反馈「候选窗位置我同步测了下是没什么问题」；记录为用户实测通过，不扩展到未说明的输入法或设备 |

输入法名称和版本未记录。后续尝试取消组字时观察到直接拉丁字母输入，因此没有把该尝试记作真实取消成功。用户同时在桌面窗口测试，后续布局回归转到独立模拟宿主页。

## 浏览器回归

环境：本地模拟 DSH 宿主页，加载实际 `client.js`、React 18 和 DSH 主题样式；通过浏览器输入工具驱动真实 DOM。

| 项目 | 结果 |
|---|---|
| 正向 Tab | 宿主前置控件 → 英文 → 中文 → 粤语 → 15 秒 → 30 秒 → 60 秒 → 输入区 → 重开 → 宿主后置控件 |
| 反向 Tab | 返回宿主前置控件，无焦点陷阱 |
| 英文连续输入 | 450 个正确字符，视区 `scrollTop=233`，外层滚动为 0，光标在视区内 |
| 英文连续退格 | 40 次退格后缓冲和正确字符数均为 410，外层滚动仍为 0 |
| 中文连续插入 | 150 个正确字符，CPM 单位，视区 `scrollTop=170`，外层滚动为 0；输入元素左边和上边与显示光标一致 |
| 粤语连续插入 | 320px 下 80 个正确字符，繁体粤语原文保留，CPM 单位，视区 `scrollTop=243` |
| 窄屏 | 320px 与 360px 无页面或插件横向溢出；360px 下当前光标保持在文本视区内 |
| 重开 | 回到首字、清空输入，焦点回到输入区 |
| 控制台 | 检查时没有捕获到 warning 或 error |

中文／粤语浏览器插入验证了实际 DOM 和反馈，不等同于真实输入法候选操作。测试工具的 `fill` 被作为粘贴拦截；长串 `pressSequentially` 在输入 36 字符后工具超时。改用原生文字输入 API，完成上表的长文本检查。工具超时未视作插件功能失败，也未计为通过案例。
